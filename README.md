# Justachae's Third-Person Skeleton and Camera

适用于 SPT 4.1.6 的客户端模组。玩的时候人物用第三人称的完整骨架和动画，游戏镜头挂在人物头上，画面看起来仍是第一人称视角。

## 1.0.4：夜视仪双眼镜头

- 目镜成像时，镜头在原地分成左右两个：各自沿镜头的右方向横移，对准自己那一侧“8”字目镜的中间镜片。主镜头当左眼，另一个镜头复制主镜头的设置渲染右眼。
- 两只眼的画面在原版夜视滤镜所在的位置合成（SSAA 阶段，HDR，色调映射之前；没有 SSAA 时用原版滤镜的命令缓冲）：左眼画面占屏幕左边，右眼占右边，中间重叠处取较亮的一方。两个中间镜片都在各自画面的正中，合成一个圆；两侧镜片各在一边，最终是三个圆连在一起。
- 夜视画面改为按整个屏幕渲染一次，两只眼共用（按视线方向取用）。
- F12“夜视仪”新增“双眼镜头”（默认打开）和“单眼画面宽度”（默认 0.7，即中间 40% 重叠）。镜头离夜视仪超过 15 厘米（例如自由镜头）时不分开。
- 右眼镜头没有主镜头上的后处理组件（抗锯齿、环境光遮蔽等），右半边的场景可能和左半边略有差别；每帧多渲染一次完整场景。已编译通过，需进游戏验证（右眼画面若上下颠倒，说明 SSAA 阶段的纹理方向与预想相反）。

## 1.0.3：目镜成像不再一闪一闪

- 自动增益原先每帧直接取画面最小一级 mip 的平均亮度，没有时间平滑；画面纹理又随目镜在屏幕上的范围按 64 像素一档频繁重建（前庭平衡让镜头相对头转动，范围每帧都在变），新纹理的 mip 未必已生成，增益就在最低和最高之间跳，画面一亮一暗。
- 现在把画面缩到 128×64 的小纹理，显式生成 mip 取平均亮度，再按 BRNVG 的 GPNVG-18 速度在两张 1×1 纹理之间做时间平滑：变亮时每秒 30、变暗时每秒 2。画面纹理只在太小或大出很多时才重建，并多留两成余量。
- 已编译通过，需进游戏验证。

## 1.0.2：头戴夜视仪的目镜成像（试验，默认关闭）

- F12 新增“夜视仪”分组：“目镜成像”开关（默认关闭）和“目镜亮度”。打开后，夜视画面不再铺满屏幕，而是只出现在夜视仪的目镜里，夜视仪模型照常画出；目镜以外是不带夜视的原样画面。BRNVG 或原版的全屏夜视滤镜在此期间跳过。目前只支持 GPNVG-18。
- 原理：夜视镜筒是 1 倍无焦系统，从眼睛穿过目镜任一点的视线，看到的就是同一方向的景物。所以从镜头位置渲染一张画面，近裁剪面斜切在夜视仪物镜前方（夜视仪、头盔、头部都不进画面），裁到四个目镜在屏幕上的范围，经过像增强管模型（光谱响应、自动增益、读出噪声和散粒噪声、颗粒、固定图案、闪烁、白色荧光）；每个目镜镜片按视线方向取这张画面，超出镜筒视场（半角 20°）的视线落在视场光阑上，只剩一点荧光。
- GPNVG-18 的几何从游戏模型里量出：中间两根镜筒朝正前方，两侧镜筒整体向外偏 26.8°；每个眼罩里两片镜片相距 26.5 毫米，通光半径 15.5 毫米，两片在中线处切开，形成“8”字和中间的细缝。
- 着色器在 `Unity/` 下的 Unity 2022.3.43f1 小项目里，`BuildShaders.Build` 打包成 `nightvision.bundle`，和 DLL 放在同一个文件夹。
- 画面里不画阴影，以节省开销。已编译通过，需进游戏验证。下一步是夜视开启时把镜头分成左右两个、各自对准一个“8”字目镜，再拼成完整画面。

## 1.0.1：可选的原版细腻手部和手表

- F12 的“人物”里新增“原版细腻手部”开关，默认关闭。打开后，自己的双手换成原版第一人称那套手部模型（例如 BEAR 默认手部约 15000 个顶点，而第三人称整件高领衫连手约 1600 个），手指细节完整；同时戴上原版第一人称的手表，表针照常走。
- 只换外观，不用原版的第一人称动作：原版本来就给每个人物加载了这套模型，只是第三人称时不画，并且蒙皮在单独的手部骨架上。现在把它按骨骼名蒙皮到第三人称骨架的同名骨骼上，动作完全由第三人称动画和本模组的手臂 IK 驱动。手表也从手部骨架移到第三人称骨架的同名骨骼（左前臂末端）上，位置不变。
- 袖子用身上衣服自己的：原版第一人称模型的袖子是另一份美术资源，和第三人称衣服的样式、长短、粗细都对不上。所以只保留它的手（按顶点在手掌、手指骨骼上的权重判断），第三人称上衣则去掉同样判断出的手部，两者在手腕处对接。两套模型在手腕处的分界基本重合。
- 穿脱护甲、胸挂、背包时上衣网格会换，去掉手部的副本随之更新。手部模型同时投射阴影。关掉开关或关闭新镜头时全部恢复原样。
- 已编译通过，需进游戏验证（重点看手腕接缝和手表位置）。

## 1.0.0：正式版

- 在 0.1.278 的基础上，反转 A 类（PU、PSO-1 系列）旧式镜片分划的移动方向：PageDown 加补偿时分划往上走，与新式分划组件路径一致。版本号定为 1.0.0。
- 所有设置的默认值改为作者实际使用的值：总开关默认打开，头部仰俯 17°，前庭平衡强度 0.7，平时的摆动 0.05、跟随头部 0.1，镜头垂直位置 0.05 米。已经保存过这些设置的玩家保持自己的值。
- 安装：把压缩包解压到 SPT 文件夹（`EscapeFromTarkov.exe` 所在的那一层），得到 `BepInEx/plugins/JustachaeThirdPersonCamera/JustachaeThirdPersonCamera.dll`；启动游戏即生效，可在 F12 里调整。

## 0.1.275：用过 AGS／固定机枪后，手里的枪不再和手臂脱节

- 原版在离开固定武器状态时，用人物创建时的视角恢复枪的程序动画模式（`Player.Init` 里的回调）。人物以第一人称创建、之后才由模组切到第三人称，于是离开 AGS 后程序动画变成第一人称模式：按第一人称把枪摆到镜头前、按 FOV 缩放胸腔，枪在第三人称骨架上脱离手臂乱飘。
- 给 `ProceduralWeaponAnimation.SetStrategy(EPointOfView)` 加前置补丁：新镜头打开、且是自己人物处于第三人称时，传入的视角改为当前的第三人称。
- 已经处在错误状态的对局，需要再上下一次固定武器，或重新进局。已编译通过，需进游戏验证。

## 0.1.274：架枪瞄准时画面不再上下颠倒

- 架枪（掩体或两脚架）瞄准时，镜头按瞄具骨骼确定朝向，其中“哪边朝上”取骨骼的 up 轴（名为 aim_camera 的骨骼取 forward 轴）。各瞄具骨骼的轴向并不统一：拆掉瞄具的莫辛，其铁瞄骨骼为 aim_camera，算出的上方实为下方，画面翻转 180°（诊断日志实测：架枪、开镜、头部锁定正常、镜头翻滚正好 180°）。
- 改为算出的上方若朝向地面就反过来：架枪瞄准的画面不会真正倒置，此规则适用于所有瞄具。原先只为固定机枪写的上下翻转特例随之删除。
- 已编译通过，需进游戏验证（含固定机枪）。

## 0.1.273：两脚架左右转动时左肘不再过度弯曲

- 架枪时转鼠标，游戏也会把“手与身体的夹角”交给身体动画，动画本身已把上身扭向枪的一部分。0.1.272 按人物根节点计算枪转了多少，等于把这部分又转了一次，上身转过头，左肩被带到左手附近，左肘弯曲过度。
- 改为按动画后的上身朝向（两肩连线的垂直方向）计算枪相对身体转了多少，只补动画没转到的部分。腰射和开镜都受影响，一并修正。
- 已编译通过，需进游戏验证。

## 0.1.272：两脚架／架枪腰射时身体跟着枪转

- 架枪但不开镜时，游戏只让枪绕架点左右转，身体留在原处，左右晃鼠标时枪和人脱节。现在记下架枪那一刻枪相对身体的水平朝向，之后枪转了多少，身体就绕同一个架点（两脚架或架枪的旋转中心）转多少，人始终在枪后面。
- 移动身体沿用开镜架枪的做法：骨盆承担位移和一半的水平转动，上身从腰部弯曲，双腿用 IK 保持双脚不动，双手保持握把。开镜时再由原有逻辑把头移到瞄具后。
- 已编译通过，需进游戏验证。

## 0.1.271：开镜时肩膀不再变形；架枪时骨盆和腿跟着动

- 开镜：原先把整条上臂连同枪平移到镜头前，上臂根部被拉出肩关节，一侧肩膀凸出、另一侧凹进。现在上臂留在肩关节，只把手移到枪被搬到的握把位置，由双骨 IK 弯肘去够；枪本身的位置和朝向不变。
- 架枪／两脚架：原先只移动腰以上，骨盆和腿不动，上身压进骨盆（肚子被挤没），左右转动时上下半身脱节。现在由骨盆承担位移和一半的水平转动，上身从腰部弯曲完成其余转动；双腿用双骨 IK（大腿、小腿、脚）让脚留在原地，膝盖弯曲来补；双手照旧回到握把。
- 手臂和腿共用同一套 IK；后坐力推胸腔时同样使用。腿的骨骼按名字（LCalf／LFoot、RCalf／RFoot）查找，找不到时退回旧做法。
- 已编译通过，需进游戏验证。

## 0.1.270：架枪瞄准和后坐力推胸腔时手臂不再扭曲

- 原因：架在掩体上或用两脚架瞄准时，模组把腰以上整段上身移到瞄具后方，同时把前臂和手掌钉在原处以保持握枪。上臂随肩膀移走而前臂不动，肘关节被拉开、扭曲。后坐力推胸腔时同样如此，幅度较小。
- 改为只记住双手握枪的位置和朝向；上身移动后，对每只手臂做双骨 IK（上臂和前臂，按余弦定理），让手回到原握把位置，肘部朝原来的一侧（随上身一起移动）自然弯曲。枪本身仍固定在原处。
- 手够不到时（上身移得过远），肘部伸直，手腕处对齐握把。
- 已编译通过，需进游戏验证。

## 0.1.269：光学密位调整范围改为 0 到 -3 mrad

- 所有 A、B 类瞄具的调整范围从 0 至 -50 mrad 缩小为 0 至 -3 mrad：PageDown 最多加 3 mrad 补偿，PageUp 回到 0，方向与按键不变。
- 3 mrad 约为 100 米归零时 7.62 mm 弹在 500 米左右的下坠，已覆盖游戏里的常见交战距离；原先 50 mrad 是实物瞄具可用上调量的数倍。
- 已在游戏里调过的补偿若超出新范围，下一次调整时会被限制到 -3。

## 0.1.263：前庭平衡在动作时保留头部转向

- 判断动作：背包打开、手上是药品或快捷使用物品、枪的手部动画层不在待机或正在过渡、身体处于搜刮／捡起／开关门／开锁／破门／接近交互／安放状态。

## 0.1.261：扭转补偿；修正上下晃鼠标时头盔一顿一顿

- 新增 F12 → 前庭平衡 → 扭转补偿（默认 0.25）。头绕视线歪斜时，镜头反向扭回这个比例；人眼的反向扭转只有头部歪斜的约一到三成。0 为完全不管翻滚，探头的歪斜也按此比例减小，最终再乘强度。
- 修正：前庭平衡原先以最新的鼠标为“想看的方向”，而头骨（以及视野边缘的头盔）按上一帧移动更新的鼠标摆姿（0.1.257 已实测）。鼠标输入不均匀时，画面比头快一帧，头盔就相对画面一顿一顿。现在想看的方向改用骨骼实际摆姿的鼠标朝向（BTR 内仍用游戏自己的转向），画面与头保持同一帧，头盔只随真实的起伏移动。画面对鼠标的响应与平衡加入前（镜头直接挂头）相同。
- 已编译通过，需进游戏验证。

## 0.1.259：前庭平衡的动态注视距离

## 0.1.257：身体骨骼按上一帧的鼠标对齐（修正 0.1.256）

- 诊断记录（藏身处，摆动全部 100%，约 4000 帧）表明：鼠标每帧的转动量并不均匀，每隔 8–12 帧会有一帧多出 1.5–2 倍；每次出现，Weapon_Root_Third 都正好晚一帧才跟上。实测它相对当前鼠标的帧间转动，与“鼠标转动量的帧间变化”相关系数 0.992、比值 1.00，即身体骨骼摆姿用的是上一帧移动更新交给动画的鼠标。
- 0.1.256 把摆姿鼠标当成了这一帧的值，晚的这一帧被当作快的晃动；摆动调到 100% 时全部保留，开镜晃鼠标就一顿一顿。现在改为使用上一帧移动更新时记录的鼠标；没有连续记录时沿用旧的“上一帧鼠标”假设。

## 做了什么改动

### 镜头和骨架

- 自己的人物改用第三人称的骨架和动画，游戏镜头每帧按头骨的位置和朝向摆放。看出去仍是第一人称，但身体、手臂和枪的动作都是第三人称那一套。
- 镜头相对头骨的朝向和位置可以在 F12 里微调。视野角度沿用游戏设置里的 FOV。
- 走路和跑步时头的左右摆动可以压小（“走路摇头”），站着不动和中键扭头不受影响。
- 第三人称下游戏会因为“看不到自己的身体”而停掉枪和手臂的程序动画，抬头跑步时枪会闪。现在自己的人物始终按看得见处理。
- 进藏身处前的俯瞰和健身房使用游戏原版的自由镜头，这时模组不接管；走进藏身处后照常接管。
- 关掉总开关会恢复第一人称和所有被改过的显示。

### 瞄准

- 瞄准时把枪和手臂摆到镜头前，瞄具对准眼睛。前后距离可以调（-0.10 到 0 米），也可以按住 PageUp / PageDown 调（按键可改）。
- 瞄准时的晃动按三种状态分开设置：平时、屏息（左 Alt）、手臂没体力。每种状态有三个滑条：
  - **摆动**：枪和手臂快的晃动（甩枪、走路、手上动作）。
  - **跟随头部**：瞄准方向跟着头的晃动走多少。
  - **呼吸**：慢的晃动（多半是呼吸）。
- 瞄具的位置像原版第一人称一样“慢半拍”追过去；枪的转动只在拉栓、切换或查看开火模式时慢半拍，动作结束后很快回正，其他时候钉在眼前。
- **跟手延迟**：晃鼠标时枪落后画面一点，开镜和腰射都用。子弹始终跟着枪口。
- 放大镜、热成像、夜视瞄具和 MP-155 智能瞄具这类自带画面的瞄具，在第三人称下也会打开镜内画面。
- 全息和红点的准星改在 TAA / DLSS 之后再画，晃动时不留虚影（始终开启）。
- 激光会按新的镜头位置重画，不会和枪脱开。

### 后坐力

- **后坐力上跳**：瞄准开枪时枪口上跳的力度，1 是原版第一人称的力度。子弹跟着枪口走。
- **后坐力传到胸腔 / 传到头部**：原版第一人称给镜头的那一下后坐力，分别推到胸腔和头上，镜头跟着头被推开再回来；枪和手留在原地。两项加起来是 1 时，镜头受到的力度和原版第一人称相同。

### 架枪、两脚架和固定武器

- 架在掩体上或打开两脚架瞄准时，头和上身跟着瞄具走，枪、前臂和手掌留在架好的位置。
- 架枪时开枪不再推动人物身体；不架枪时照原版。
- 固定机枪和 AGS 榴弹发射器可以正常瞄准。AGS 的瞄具外壳只左右转，镜内画面对准榴弹实际会落到的地方。

### 中键自由看

- 按住鼠标中键自由看时，从脖子转头和低头，身体和枪不动。
- 左右最多转多少度、比原版多低多少度、转头那根轴前后倾斜多少，都可以在 F12 里调。

### 人物显示

- 头部默认不画，只投影子。头部装备、面部装备、眼部装备和面罩玻璃上的滤镜可以分别开关。
- 头盔或面罩上挂的夜视和热成像，要等它自己的滤镜真正亮起才藏起来，滤镜关掉就再画出来。兼容 BorkelRNVG 夜视模组。
- 头部模型可以单独往上或往下转（“头部仰俯”），镜头不跟着动。

### 声音

- 第三人称下游戏会按第三人称播放自己的声音。现在总开关打开时，按第一人称处理自己的声音。
