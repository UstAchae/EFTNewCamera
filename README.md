# Justachae's Third-Person Skeleton and Camera

适用于 SPT 4.1.6 的客户端模组。玩的时候人物用第三人称的完整骨架和动画，游戏镜头挂在人物头上，画面看起来仍是第一人称视角。

## 0.1.245：镜内重复叠画裁剪和双交点距离

- 主视野GUI线段在当前光学镜片的屏幕投影包围区域内裁掉，镜内仅保留光学摄像头的绘制。包围区域根据镜片网格及旧式着色器遮罩缩放／偏移计算，采用保守矩形，因此镜框附近也可能少一小段主视野调试线。此裁剪用于所有调试线和标记，防止黄线、紫线及叉号重复叠画。
- 紫线对应的世界射线仍是唯一距离计算基准，不把主摄像头的屏幕线反推为瞄准方向。右下角同时显示近、远交点；各自小于50米时显示 `< 50 m`，只有一个交点时另一栏显示 `—`。镜内保留全部有效交点的绿色叉号。
- 增加穿过镜片、完全位于镜片内／外、离开镜片的裁剪回归，以及双交点、单交点和无交点显示检查。实际镜片边界和最终画面仍需进局验证。

## 0.1.244：以紫色原生节点轴为瞄准基准

- 移除青色相机中心估算线；紫线零位使用游戏原生瞄准节点位置／轴向，绿叉及右下角距离都使用当前紫线。
- A类保持轴向不变，以实际分划纹理UV平移量、材质缩放和网格UV方向换算世界位移。PU／PSO原生网格不可CPU读取时，使用从SPT 4.1.6原资源中央UV三角形提取的数据，并核对型号、网格名、顶点数和尺寸；不另设毫米／mrad比例。该换算是中央区域的局部映射，未自动识别尖端像素，极端偏移处与最终着色画面的吻合仍需进局确认。
- B类也使用原生节点零位，计入现有镜内场景投影带来的方向差。保留原有A/B调节手感、黄线弹道、红色终点以及近交点／50米显示规则。旧基准X/Y设置不再参与计算。
- 离线验证包括平移方向、轴向保持平行、屏幕位移换算与原生四款A类网格回退；不把离线计算通过当成实机画面对齐已确认。

## 0.1.243：主视野弹道投影修正

- 移除0.1.242新增的SSAA最终合成补画；主视野改为用主相机将世界坐标直接投影到屏幕，裁剪相机背后及屏幕外的线段。镜内仍使用光学相机绘制。
- 主视野绘制前重新采样当前骨架姿态，弹道和距离估算都从实体枪口Original.position读取位置，避免BifacialTransform缓存位置与可见枪口不同步。
- 保留实际发射向量的预测校正、黄色轨迹、红色终点及A/B类密位调节。编译通过；镜头转动时与枪口、背景的对齐仍需游戏内验证。

## 0.1.242：瞄准基准／交点可视化和主视野弹道

- F12 → 等效归零距离 → 显示瞄准基准与交点，默认开启，需要同时启用弹道调试。青色射线是当前估算算法实际使用的基准，绿色叉标出其全部有效交点，主读数仍选近交点。
- 紫色点和线是当前游戏SightNBone.Bone的原生节点位置／轴向（沿插件持枪对齐使用的节点轴定义）；紫叉为该轴与理论弹道的有效交点。明确与青色估算射线区分，不声称它已经对应分划纹理尖端。
- 黄色实线及红色首次碰撞终点保留。瞄准基准调试开启时，用黄色虚线延伸忽略碰撞的理论弹道，方便观察墙后远交点；这不表示子弹可以穿过墙。
- 射线默认绘制至50000米模拟无限延长，可在弹道调试里调节；实际可见部分受相机远裁剪限制，交点仍只计算至既有最大距离／20秒。
- 在SSAAPropagator最终合成结果中补画主视野的世界空间线条，保留镜内绘制；避免仅在镜内看到黄线。绘制只读世界坐标，不改枪口与弹道。
- 编译检查通过。世界视野可见性、原生节点轴与估算射线的对应仍需进局观察；正对射线时会投影成点，可中键侧看辅助检查。

## 0.1.241：距离改取近交点

- 按要求，等效归零距离改为取最近的有效交点。即使远交点超过50米，只要近交点小于50米也显示 `< 50 m`；无有效交点仍显示 `—`。

## 0.1.240：等效归零距离试验读数

- F12 → 等效归零距离 → 显示估算距离，默认开启。瞄准已接管的A/B类瞄具时，在右下角单独显示，不替换原版归零档位。
- 用当前弹药、初速系数、枪口位置／方向及G1阻力、重力积分理论弹道，与计入A/B类调节量的三维瞄准射线求交；忽略场景碰撞，与黄线是否启用无关。
- 优先显示有效远交点，≥50米显示一位小数；<50米显示 `< 50 m`；范围内无交点或横向未重合显示 `—`。默认计算至2000米／20秒，横向容差0.1mrad，可配置。
- 首版以原版画面中心为初始瞄准点，未自动识别逐镜的尖柱／尖角，显示为“估算”。F12基准X/Y可手动校准；不把小数位当成真实精度。
- 合成强制偏移测试开启时显示无效读数。已通过本地程序集编译及交点插值、双交点、50米阈值、横向不重合等离线回归；实际弹着需进局验收。

## 0.1.239：旧式A类直接平移分划纹理

- 0.1.238日志证明新材质已提交且21mrad对应材质参数已改变，但用户画面仍无变化；不能据此认定旧式着色器几何参数方案有效。

## 安装

1. 把压缩包解压到 SPT 文件夹（`EscapeFromTarkov.exe` 所在的那一层）。解压后文件在：
   `BepInEx/plugins/JustachaeThirdPersonCamera/JustachaeThirdPersonCamera.dll`
2. 启动游戏，按 F12 打开设置，在 **新镜头 → 总开关** 打开。**总开关默认是关的。**
3. 设置保存在 `BepInEx/config/justachae.thirdpersoncamera.cfg`。

只改客户端，不需要服务端模组。

## 做了什么改动

### 镜头和骨架

- 自己的人物改用第三人称的骨架和动画，游戏镜头每帧按头骨的位置和朝向摆放。看出去仍是第一人称，但身体、手臂和枪的动作都是第三人称那一套。
- 镜头相对头骨的朝向和位置可以在 F12 里微调。视野角度沿用游戏设置里的 FOV。
- 走路和跑步时头的左右摆动可以压小（“走路摇头”），站着不动和中键扭头不受影响。
- 第三人称下游戏会因为“看不到自己的身体”而停掉枪和手臂的程序动画，抬头跑步时枪会闪。现在自己的人物始终按看得见处理。
- 进藏身处前的俯瞰和健身房使用游戏原版的自由镜头，这时模组不接管；走进藏身处后照常接管。
- 关掉总开关会恢复第一人称和所有被改过的显示。

### 瞄准

- 瞄准时把枪和手臂摆到镜头前，瞄具对准眼睛。前后距离可以调（-0.10 到 0 米），也可以按住 PageUp / PageDown 调（按键可改）。
- 瞄准时的晃动按三种状态分开设置：平时、屏息（左 Alt）、手臂没体力。每种状态有三个滑条：
  - **摆动**：枪和手臂快的晃动（甩枪、走路、手上动作）。
  - **跟随头部**：瞄准方向跟着头的晃动走多少。
  - **呼吸**：慢的晃动（多半是呼吸）。
- 瞄具的位置像原版第一人称一样“慢半拍”追过去；枪的转动只在拉栓、切换或查看开火模式时慢半拍，动作结束后很快回正，其他时候钉在眼前。
- **跟手延迟**：晃鼠标时枪落后画面一点，开镜和腰射都用。子弹始终跟着枪口。
- **鼠标抹匀**：把鼠标转动抹匀后再交给游戏，画面、人物和枪一起转得更顺。
- 放大镜、热成像、夜视瞄具和 MP-155 智能瞄具这类自带画面的瞄具，在第三人称下也会打开镜内画面。
- 全息和红点的准星改在 TAA / DLSS 之后再画，晃动时不留虚影（始终开启）。
- 激光会按新的镜头位置重画，不会和枪脱开。

### 后坐力

- **后坐力上跳**：瞄准开枪时枪口上跳的力度，1 是原版第一人称的力度。子弹跟着枪口走。
- **后坐力传到胸腔 / 传到头部**：原版第一人称给镜头的那一下后坐力，分别推到胸腔和头上，镜头跟着头被推开再回来；枪和手留在原地。两项加起来是 1 时，镜头受到的力度和原版第一人称相同。

### 架枪、两脚架和固定武器

- 架在掩体上或打开两脚架瞄准时，头和上身跟着瞄具走，枪、前臂和手掌留在架好的位置。
- 架枪时开枪不再推动人物身体；不架枪时照原版。
- 固定机枪和 AGS 榴弹发射器可以正常瞄准。AGS 的瞄具外壳只左右转，镜内画面对准榴弹实际会落到的地方。

### 中键自由看

- 按住鼠标中键自由看时，从脖子转头和低头，身体和枪不动。
- 左右最多转多少度、比原版多低多少度、转头那根轴前后倾斜多少，都可以在 F12 里调。

### 人物显示

- 头部默认不画，只投影子。头部装备、面部装备、眼部装备和面罩玻璃上的滤镜可以分别开关。
- 头盔或面罩上挂的夜视和热成像，要等它自己的滤镜真正亮起才藏起来，滤镜关掉就再画出来。兼容 BorkelRNVG 夜视模组。
- 头部模型可以单独往上或往下转（“头部仰俯”），镜头不跟着动。

### 声音

- 第三人称下游戏会按第三人称播放自己的声音。现在总开关打开时，按第一人称处理自己的声音。

## 自己编译

需要 SPT 4.1.6 游戏目录。把源码放在 SPT 文件夹下的一个子文件夹里，用 PowerShell 7 运行：

```powershell
pwsh -NoProfile -File Build-Local.ps1
```

输出在 `_build/`：`JustachaeThirdPersonCamera.dll`，以及可以直接解压到 SPT 文件夹的 `JustachaeThirdPersonCamera-<版本>.zip`。
